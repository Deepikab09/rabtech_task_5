## How to run
1. Open the notebook in Google Colab or Jupyter Notebook.
2. If needed, install dependencies: `tensorflow`, `scikit-learn`, and `matplotlib`.
3. Run all cells from top to bottom.
4. Wait for the IMDB dataset to download and for model training to finish.
5. Save or download the executed notebook with training curves, test metrics, confusion matrix, and sample predictions visible.

## Dataset and model
Uses the IMDB movie review dataset available through `tensorflow.keras.datasets.imdb`.
The model uses an Embedding layer, Global Average Pooling, Dense layers, Batch Normalization, Dropout, and Early Stopping.
